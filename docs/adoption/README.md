# Adoption Kit

Fast-start assets to promote and validate the skill externally.

## Files

- `before-after.md`: copy-paste snippets for comments rewrites
- `launch-post.md`: short post template for X/LinkedIn/GitHub

## Recommended Rollout Sequence

1. Record or capture `media/cursor-demo.gif` (or `media/cursor-demo.png`).
2. Add the selected visual in root `README.md`.
3. Publish one short post using `launch-post.md`.
4. Reuse snippets from `before-after.md` in replies and issue threads.
