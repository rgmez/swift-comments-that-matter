# Adoption Kit

Ready-to-use assets to promote and validate the skill externally.

## Files

- `before-after.md`: copy-paste snippets for comments rewrites
- `launch-post.md`: short post draft for X/LinkedIn/GitHub
- `.github/SOCIAL_POST_SHORT.md`: compact social variant

## Recommended Rollout Sequence

1. Publish one short post using `launch-post.md`.
2. Reuse snippets from `before-after.md` in replies and issue threads.
3. Use `.github/SOCIAL_POST_SHORT.md` for fast reposts and updates.
