# Context - Swift Comments That Matter

This skill is based on real-world patterns observed in production iOS codebases.

The goal is not to teach how to write comments.
The goal is to teach when and what to comment.

Most developers already know how to write comments.
What they struggle with is writing useful ones.

This skill focuses on:

- avoiding useless comments
- documenting intent instead of implementation
- capturing invariants and constraints
- making code safer to change

## Tone

- Human
- Direct
- No robotic-sounding phrases
- No tutorial tone
- No over-explaining basics

## Avoid

- "This function does..."
- "This method is responsible for..."
- generic explanations
- toy examples

## Prefer

- real-world scenarios
- edge cases
- trade-offs
- imperfect decisions found in real systems
